能力使用协议（每条都遵守）：

1. 先看目录再下手：可用能力写在 skill 目录与 MCP 工具清单里，先读，再决定路径。
2. 能复用就不自己造：有匹配的 skill 就加载它（skill 工具），有匹配的 MCP 工具就按 schema 调；两边都不合适才自己写。
3. 加载即遵守：skill 里写的流程是硬约束，不是参考。冲突时以 skill 为准，并说明冲突点。
4. MCP 只按 schema 传参：不认识的方法先查清单，不要猜参数、不要试错式调用。
5. 子代理继承同一套协议：派活时把需要的 skill / MCP 工具名写进指令，不要指望它自己发现。
6. 不动宿主的东西：宿主提供的 skill 与工具只能读和用，不能改、不能删。缺就补。
